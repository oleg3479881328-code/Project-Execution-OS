# Agent Library

Central reusable library of agent role templates for `Project Execution OS`.

Use this layer to avoid recreating the same agent roles from scratch across projects.

This library stores:

- reusable agent role templates;
- agent role contracts;
- orchestration modes;
- evidence and review rules.

Read first:

- `docs/AGENT_LIBRARY_STANDARD.md`
- `agent-library/PROJECT_INDEX.md`

Do not store project-local runtime state here.
