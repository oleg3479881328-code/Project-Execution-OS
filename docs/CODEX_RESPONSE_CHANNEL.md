# Codex Response Channel

Status: Active

For GitHub-coordinated work, the task must include the exact GitHub URL where the executor posts its result.

Use this field:

`Response URL: <GitHub issue, pull request, or review-thread URL>`

The executor result belongs in that GitHub thread as a new comment. If work cannot continue, the blocker belongs in the same thread.

A task is not complete until the response appears in the named thread.
