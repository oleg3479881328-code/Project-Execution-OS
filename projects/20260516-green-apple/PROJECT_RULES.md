# PROJECT RULES — Green Apple

## 1. Project Scope

This project is a landing page about:

- growing green apples;
- processing harvested apples;
- selling apple-based products.

## 2. Current MVP Boundary

The current goal is not to build a full website backend.

The current goal is to define the landing page concept, structure, message, audience, offer, and execution specification.

## 3. Forbidden Current Actions

Do not build yet:

- backend;
- payment system;
- CRM;
- ecommerce engine;
- automation layer;
- inventory system;
- farm management system.

## 4. Required Work Style

Work through the Project Execution OS workflow.

Do not skip straight to final design or code.

## 5. Evidence Rules

If making market, agriculture, food processing, or sales claims, mark whether the claim is:

- user-provided;
- researched;
- assumption;
- recommendation.

## 6. Landing Page Output Rules

The landing page specification must eventually define:

- target audience;
- main offer;
- hero section;
- product sections;
- proof/trust section;
- process section;
- call to action;
- visual direction;
- content blocks;
- acceptance criteria.

## 7. Agent Rules

Do not create project agents unless the workflow shows a real need.

Candidate agents may be proposed in `04_AGENT_DESIGN.md`.

## 8. Knowledge Rules

Project-specific lessons go to:

`project-library/`

Reusable lessons may later be promoted to root `knowledge-library/` after review.
