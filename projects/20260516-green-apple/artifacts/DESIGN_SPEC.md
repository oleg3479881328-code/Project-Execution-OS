# DESIGN SPEC — Green Apple Landing MVP

## Goal

Create a clean static B2B landing page for Green Apple.

## Style Direction

Clean modern agro-premium.

## Visual Principles

- White background.
- Deep green primary color.
- Fresh light green accent.
- Soft cream background sections.
- Large typography.
- Rounded cards.
- Clear B2B trust sections.
- Premium but simple layout.

## Page Sections

1. Hero
2. B2B Problem
3. Green Apple Solution
4. Products
5. Processing
6. Quality
7. Ohio Supply
8. Partnership
9. CTA Form

## Layout

Use one-page vertical layout.

Maximum content width:
1100px to 1200px.

Responsive:
- desktop: two-column hero, cards in grids;
- tablet: stacked grids;
- mobile: single column.

## Color Palette

- Primary green: #1F5E3B
- Dark text: #102015
- Soft green: #EAF5EC
- Accent green: #83B735
- Cream: #FAF7EE
- Border: #DCE8DD
- White: #FFFFFF

## Typography

Use system fonts:

- Inter-like stack: system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, sans-serif.

## Components

- Sticky or simple top nav.
- Hero with primary and secondary CTA.
- Problem cards.
- Three-step process strip.
- Product cards.
- Quality checklist.
- Ohio local supply panel.
- Buyer type cards.
- CTA form.
- Footer with concept disclaimer.

## Image Strategy

MVP should not require real images.

Use:
- gradient blocks;
- emoji/apple visual accents only if tasteful;
- simple cards;
- CSS shapes.

Do not use fake farm photos or fake product packaging.

## Claim Safety

Must preserve concept honesty.

Use copy such as:

- preparing;
- planning;
- being developed;
- future supply;
- buyer interest.

Avoid:

- operating now;
- guaranteed supply;
- certified;
- proven capacity;
- existing clients;
- current delivery network.

## CTA Form Fields

- Contact name
- Company name
- Buyer type
- Product interest
- Expected volume range
- Ohio region / delivery location
- Desired timeline
- Email
- Phone
- Message

## MVP Acceptance Criteria

- Static HTML/CSS page works locally.
- No external build tools needed.
- Responsive layout.
- All sections present.
- CTA form visible.
- No fake operational claims.
- Page can be opened directly as `index.html`.
