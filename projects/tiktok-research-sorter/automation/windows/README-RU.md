# Автоматическое обновление и запуск — Windows 11

## Первый запуск

1. Распакуйте ZIP-пакет в обычную папку.
2. Дважды нажмите `Install-TikTok-Sorter.cmd`.
3. Разрешите Windows выполнить PowerShell-сценарий, если появится предупреждение.
4. Сценарий создаст на рабочем столе ярлык `TikTok Sorter — обновить и запустить`.
5. При отсутствии Node.js сценарий установит Node.js LTS через `winget`.
6. Первый запуск может занять несколько минут: скачивается исходный код, устанавливаются зависимости и собирается расширение.

## Каждый следующий запуск

Дважды нажимайте ярлык на рабочем столе. Он автоматически:

1. скачает текущую версию проекта из GitHub;
2. обновит зависимости только при необходимости;
3. соберёт расширение;
4. закроет только специальное тестовое окно Chrome;
5. откроет новый Chrome с последней версией расширения.

Используется отдельный постоянный профиль Chrome. Войти в TikTok и закрепить значок расширения потребуется только один раз.

## Где находятся файлы

- Рабочая копия: `%LOCALAPPDATA%\TikTokResearchSorterDev`
- Постоянный Chrome-профиль: `%LOCALAPPDATA%\TikTokResearchSorterDev\chrome-profile`
- Журнал ошибок: `%LOCALAPPDATA%\TikTokResearchSorterDev\launcher.log`
- Файлы ярлыка: `%LOCALAPPDATA%\TikTokResearchSorterLauncher`

## Важно

До слияния проекта в `main` обновлятор получает код из ветки `agent/tiktok-research-sorter-mvp`. После слияния стандартная ветка в сценарии будет изменена на `main`.
