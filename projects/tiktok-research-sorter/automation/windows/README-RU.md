# Автоматическое обновление и запуск — Windows 11

## Первый запуск

1. Распакуйте ZIP-пакет в обычную папку.
2. Дважды нажмите `Install-TikTok-Sorter.cmd`.
3. Разрешите Windows выполнить PowerShell-сценарий, если появится предупреждение.
4. Сценарий создаст на рабочем столе ярлык `TikTok Sorter — обновить и запустить`.
5. При отсутствии Node.js сценарий установит Node.js LTS через `winget`.
6. Первый запуск может занять несколько минут: исходный код скачивается, затем выполняются воспроизводимая установка зависимостей, TypeScript-проверка, тесты и production build.

## Каждый следующий запуск

Дважды нажимайте ярлык на рабочем столе. Он автоматически:

1. скачает текущую версию проекта из ветки `main`;
2. подготовит отдельную кандидатную папку;
3. выполнит `npm ci`, TypeScript-проверку, тесты и сборку;
4. проверит созданный `manifest.json`;
5. заменит рабочую версию только после полного успеха;
6. сохранит предыдущую рабочую версию в папке `previous`;
7. закроет только специальное окно Chrome;
8. откроет новый Chrome с проверенной версией расширения.

При ошибке действующая версия не заменяется. Используется отдельный постоянный профиль Chrome, поэтому вход в TikTok и настройки сохраняются между запусками.

## Служебные режимы

```powershell
-DryRun
```

Показывает план и не создаёт файлов или папок.

```powershell
-SkipLaunch
```

Проверяет и устанавливает сборку, но не запускает Chrome.

```powershell
-NonInteractive
```

Не ожидает нажатия Enter при ошибке; используется в CI.

```powershell
-LocalSource "C:\путь\к\проекту"
```

Проверяет локальную копию вместо скачивания ветки GitHub.

Переменная `TRS_GITHUB_BRANCH` позволяет временно проверить другую ветку, но обычный пользовательский запуск всегда использует `main`.

## Где находятся файлы

- Текущая проверенная версия: `%LOCALAPPDATA%\TikTokResearchSorterDev\source`
- Предыдущая версия для отката: `%LOCALAPPDATA%\TikTokResearchSorterDev\previous`
- Постоянный Chrome-профиль: `%LOCALAPPDATA%\TikTokResearchSorterDev\chrome-profile`
- Журнал: `%LOCALAPPDATA%\TikTokResearchSorterDev\launcher.log`
- Файлы ярлыка: `%LOCALAPPDATA%\TikTokResearchSorterLauncher`
