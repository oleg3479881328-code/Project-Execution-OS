## Purpose

`Website Creation` is the canonical entrypoint for everything we have learned, built, tested, standardized, or adopted for creating websites.

The project solves context fragmentation: website knowledge has accumulated across Olga Polo Weddings, Tusia/Tasha Hurley, Automatic Website Factory, SOFT, PEOS Design Block, design-extractor work, editor/CMS work, deployment/infrastructure notes, SEO/AEO systems, AI website-builder research, separate chats and external donor reviews.

A fresh chat must be able to answer: **how do we create this site using our existing proven system?** without asking the owner to reconstruct prior work from memory.

The project covers the full website lifecycle:

- business/client discovery and source research;

- donor-first visual research and design extraction;
- design systems, sections, components, responsive behavior and motion;
- content generation, editorial rules and structured content;
- CMS/editor/authoring architecture and safe client editing;
- image/media handling, crop/focal/positioning and gallery patterns;
- SEO, local SEO, pSEO, AEO/GEO, schema, canonical, sitemap and indexing;
- frontend implementation and reusable renderers/components;
- Git/GitHub workflow, preview/staging, QA and release semantics;
- Vercel/Netlify/Showit/WordPress/Framer/Duda/10Web and other execution paths;
- site audit/baseline scanning and design extraction tools;
- AI-assisted and agentic website creation workflows;
- Automatic Website Factory / local-business preview-first sales system;
- cost, speed, quality and repeatability improvements.

6. Adapt/integrate existing solutions.
7. Custom build only for a demonstrated gap.

Canonical standard: `../../docs/EXISTING_SOLUTION_FIRST_STANDARD.md`.

## Core Production Principle

Do not equate generated code, a template, a successful build, or a local/preview URL with a finished website.

A general production chain is:

`SOURCE / RESEARCH READY → CONTENT + DESIGN READY → IMPLEMENTED → QA PASS → PREVIEW / STAGING → LIVE VERIFY → RELEASED / PUBLISHED`

For sales-factory use cases this extends to:

`DISCOVERY → QUALIFICATION → DOSSIER → SITE → SAFE EDITOR → QA → PREVIEW → OUTREACH/TRIAL → SALE → DOMAIN/OWNERSHIP TRANSFER → SUPPORT`.
