# Personal Secretary OS — Document Saving Standard

## Purpose

Define the default procedure for receiving, cleaning, indexing, and saving personal documents so the owner does not need to renegotiate the workflow for every document.

## Trigger

Apply this standard whenever Oleg sends a photograph or scan of a personal document and asks to save, organize, archive, or record it.

## Default Workflow

1. Accept the raw photograph or scan in the active secretary conversation.
2. Create a scan-style derivative when the source is a casual phone photo:
   - correct perspective;
   - crop background;
   - improve legibility gently;
   - preserve the original document content;
   - do not regenerate, rewrite, translate, or alter printed text.
3. When one photograph contains several practically useful document parts, create separate scan-style files for each useful part in addition to any overview scan. This especially applies to receipts, stickers, cards, attachments, and inserts that should be readable or stored separately.
4. Extract the practical document data into a compact text card.
5. Show the proposed text card when review is useful.
6. After owner confirmation, create or update the corresponding Notion record.
7. Include a place for the original or scan-style file and a separate Google Drive URL field.
8. When direct attachment from ChatGPT into Notion is unavailable, provide the prepared scan-style file for download and state once that manual attachment is required.
9. Record the document status as current, archived, expired, or requires review.
10. Identify any expiry date or next action when present.

## Text Card Minimum Fields

Use only the fields relevant to the document type:

- document type;
- owner, vehicle, property, or other subject;
- key identifiers and numbers;
- issue date;
- expiry date;
- current status;
- original or scan-style file location;
- Google Drive URL when available;
- notes;
- nearest useful next action when required.

## Data Handling Rule

Ordinary personal data from documents may be saved without repeated warnings when the owner has asked to organize the document.

Do not store passwords, access tokens, bank-card data, Social Security numbers, or comparable secrets in the personal document index.

## Current Tool Boundary

- Notion text cards can be created and edited.
- Direct transfer of a local chat image into Notion as an attachment is currently unavailable through the connected tool surface.
- Google Drive search and reading are available, but direct file upload is not available through the connected Drive tool surface.
- Until those capabilities change, provide a prepared file for manual upload and keep a URL field in the Notion card.

## Interaction Rule

- Do not repeat the entire workflow every time. Apply it automatically and mention only exceptions, blockers, or the one next action needed from the owner.
- When the response contains a primary page or file link that the owner is expected to open, upload, or use next, show that key link near the beginning of the response and repeat the same key link again as the final line of the response.
