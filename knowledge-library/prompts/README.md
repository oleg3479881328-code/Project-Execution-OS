# Prompts

## Purpose

This section stores reusable prompt assets that are worth preserving for future use across projects.

## Scope

Store here:

- reusable prompt templates;
- prompt variants for specific roles or tasks;
- tested prompt patterns;
- notes about when a prompt works well or should not be used.

Do not store here:

- random chat fragments;
- unreviewed giant prompt dumps;
- project-only prompts that belong inside a specific project;
- mandatory system rules, which belong in the relevant standards or integration configuration.

## Recommended Entry Format

Each prompt entry should include, when useful:

- title;
- purpose;
- lifecycle status;
- applies to;
- trigger;
- prompt text;
- variables or placeholders;
- usage notes;
- known limits;
- source or project of origin;
- review status.
