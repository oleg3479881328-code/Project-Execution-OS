# Pattern — Document-First MVP

## Status

candidate

## Source

migrated_from_3TestAgents

## Purpose

Prevent premature engineering complexity.

## Pattern

Before building:
- backend;
- runtime;
- orchestration;
- automation;
- UI;
- semantic search;
- databases;
- execution engines;

first validate:
- workflow structure;
- governance rules;
- lifecycle model;
- repository model;
- review process;
- reusable artifact quality.

## Why This Exists

AI projects often fail because implementation starts before operational structure stabilizes.

## When to Use

Use this pattern:
- during early-stage AI systems;
- during workflow architecture;
- before automation exists;
- before scaling skill libraries.

## When Not to Use

Do not stay permanently document-only.

Once workflows stabilize and reuse becomes predictable, implementation systems can become valid.
