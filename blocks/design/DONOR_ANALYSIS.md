# Donor Analysis

## Purpose

Teach agents to start from proven websites instead of inventing layouts from zero.

## Core Principle

Design = Research + Adaptation.

Do not start by drawing.

Start by finding the strongest existing solutions.

## Donor Categories

### Landing Pages

Capture:

- hero section;
- CTA pattern;
- social proof;
- pricing;
- FAQ.

### SaaS

Capture:

- onboarding;
- dashboard structure;
- navigation;
- pricing;
- upgrade flow.

### AI Products

Capture:

- input flow;
- output presentation;
- trust signals;
- upgrade flow.

### Portfolios

Capture:

- presentation structure;
- storytelling;
- project showcase.

### Marketplaces

Capture:

- search;
- filters;
- listing pages;
- checkout path.

## Required Review Questions

- Why is this design successful?
- What should be reused?
- What should not be reused?
- Which audience does it target?
- Which conversion goal does it optimize?

## Final Rule

At least 3 donor websites should be reviewed before proposing a major new website design.
