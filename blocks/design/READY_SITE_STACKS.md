# Ready Site Stacks

## Purpose

Provide reusable website architecture bundles so agents do not redesign the technical foundation of every website from scratch.

## Landing MVP

Stack:

- React
- Vite
- Tailwind
- Cloudflare Pages

Use when:

- validating an idea;
- collecting leads;
- simple marketing site.

## SaaS MVP

Stack:

- Next.js
- Supabase
- Stripe
- Cloudflare

Use when:

- auth is required;
- subscriptions are required;
- dashboard exists.

## AI SaaS

Stack:

- Next.js
- Supabase
- Stripe or Paddle
- AI Backend

Use when:

- AI is a core product feature;
- paid usage exists.

## Portfolio Builder

Stack:

- Astro
- Tailwind
- Cloudflare

Use when:

- portfolio;
- personal brand;
- showcase site.

## Directory Website

Stack:

- Next.js
- Supabase
- Search layer

Use when:

- listings;
- catalogues;
- searchable databases.

## Marketplace

Stack:

- Next.js
- Supabase
- Stripe Connect

Use when:

- multiple sellers;
- commissions;
- transactions.

## Agency Website

Stack:

- Next.js
- Tailwind
- CMS

Use when:

- services business;
- marketing site;
- content updates.

## Education Platform

Stack:

- Next.js
- Supabase
- Stripe
- Video provider

Use when:

- courses;
- memberships;
- learning products.

## Final Rule

Choose website type first, stack second.
