# Website Review Checklist

## Purpose

Provide a compact checklist for reviewing a website draft before build or before revision.

## Review Order

1. Goal clarity
2. Audience clarity
3. Message hierarchy
4. Section order
5. CTA visibility
6. Trust and proof
7. Visual consistency
8. Mobile behavior
9. Component states
10. Build readiness

## Output Format

Use:

- verdict;
- strongest part;
- main weakness;
- required fixes;
- optional improvements;
- build risks.

## Checks

### Goal

The page must have one primary goal.

### Audience

The visitor must understand whether the page is for them.

### Message

The headline, subheadline, and first screen must explain the product or offer.

### CTA

The main action must be visible and specific.

### Proof

The page must include enough trust for the requested action.

### Visual System

Typography, spacing, color, cards, buttons, and forms must feel consistent.

### Mobile

The mobile version must preserve message, action, and readability.

### Build

The design must be possible to implement with clear sections, components, and states.

## Final Rule

A useful review gives decisions, not vague taste comments.
