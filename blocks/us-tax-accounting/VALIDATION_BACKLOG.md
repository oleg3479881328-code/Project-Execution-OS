# Validation Backlog

## Purpose

Separate researched structure from workflows that still require practical validation.

## Status

This block remains `candidate` until it is used and reviewed on real cases.

## Required Validation Scenarios

- income-channel capture;
- mileage and vehicle record workflow;
- state and local routing;
- estimated-tax review;
- year-end handoff.

### Scenario 2 — Solo SaaS Founder

- single-owner entity intake;

## Open Questions

- Should annual dated snapshots be generated as one file or split by federal, state, and local scope?
- Which bookkeeping-tool comparisons deserve maintained current snapshots?
- Which state-specific sub-blocks are justified after repeated use?
- Should Ohio municipal-income-tax routing receive an early sub-block because local routing is likely to recur?
- Which gig-economy templates should be promoted into ready-to-fill worksheets?
- Should sales-tax routing become a separate reusable sub-block after practical validation?

## Validation Record Template

For each real use, record:

- scenario;
- date;
- project;
- files opened;
- workflow used;
- gaps found;
- corrections made;
- sources verified;
- professional feedback;
- promotion decision.

## Final Rule

Research is not validation. Keep assumptions visible until real workflows confirm them.
