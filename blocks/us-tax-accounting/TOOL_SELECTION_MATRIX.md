# Tool Selection Matrix

## Purpose

Choose software based on the workflow that must be supported.

## Categories

Review as applicable:

- bookkeeping;
- receipt capture;
- bank transaction import;
- payment processor reconciliation;
- mileage tracking;
- invoicing;
- payroll;
- contractor records;
- information returns;
- sales tax;
- ecommerce integrations;
- expense management;
- document organization;
- close checklist management;
- accountant collaboration;
- reporting and exports.

## Selection Questions

For each tool, verify:

- supported business types;
- supported jurisdictions;
- payroll coverage;
- sales tax coverage;
- marketplace integrations;
- bank and card connections;
- export quality;
- accountant access;
- change history;
- security settings;
- data portability;
- pricing model;
- migration path;
- automation support;
- current official documentation.

## Evaluation Table

Use these columns:

- workflow;
- candidate tool;
- official source;
- supported use case;
- limitations;
- setup effort;
- recurring cost;
- migration risk;
- professional compatibility;
- decision status.

## Boundary

Do not hard-code one universal stack. A gig-economy side-income workflow, a solo SaaS founder, an employer with payroll, and an ecommerce seller may require different tools.

## Final Rule

Prefer simple systems that export cleanly, support review, preserve history, and reduce manual reconciliation.
