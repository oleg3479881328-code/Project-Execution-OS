# Blocks

Blocks are reusable domain modules embedded inside `Project-Execution-OS`.

A block is not a separate operating system.

A block is a focused, reusable capability layer that:
- has a clear purpose;
- defines when to use and when not to use it;
- contains its own standards, templates, and examples when useful;
- depends on central OS rules instead of replacing them.

Use blocks when a domain is mature enough to deserve a stable reusable home inside the central brain.
