# Chrome Extension References

## Purpose

Preserve source URLs for browser-extension work. Official sources outrank vendor marketing, community examples, and forum reports.

## Source Hierarchy

1. Official Chrome / Chromium / Chrome Web Store documentation.
2. Official framework documentation.
3. Official payment-provider documentation.
4. Maintained GitHub repositories.
5. Professional articles and community examples.
6. Forum or anecdotal signals.
