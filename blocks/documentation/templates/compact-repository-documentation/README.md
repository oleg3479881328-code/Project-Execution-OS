# Compact Repository Documentation Template

## Purpose

This template defines a compact workflow for analyzing a repository and producing an AI-ready documentation package.

## When To Use

Use this template when the task is to produce:
- documentation analysis;
- generated AI-ready documentation package;
- checklist;
- review;
- log.

## Template Files

```text
00_INPUT.md
01_CLARIFICATION.md
02_ANALYSIS.md
03_RESULT_PACKAGE.md
04_REVIEW.md
05_LOG.md
CHECKLIST.md
```

## Rule

Keep the run compact while preserving separation between:
- input;
- clarification;
- analysis;
- result package;
- checklist;
- review;
- log.
