# Logic Block Resource Map

## Purpose

This file stores a compact, reusable source map for learning, teaching, and applying logic inside `Project Execution OS`.

Use it when an agent needs courses, learning materials, or ready-made tools for logic, argument analysis, critical thinking, and reasoning review.

Research date: 2026-06-06.

## Selection Rule

Prefer resources that are:

- institution-backed, open, or widely used;
- useful for practical reasoning, not only academic symbolic logic;
- reusable across projects and agents;
- clear about whether they teach formal logic, informal logic, argument mapping, or critical thinking.

## Best Courses

### MIT OpenCourseWare — Logic I

URL: https://ocw.mit.edu/courses/24-241-logic-i-fall-2009/

Use for: serious formal logic foundation.

Why it matters:

- undergraduate MIT course;
- includes syllabus, readings, lecture notes, assignments, exams, and problem-set solutions;
- covers validity, soundness, formal derivations, truth-functions, formal language translation, truth tables, sentential calculus, predicate logic, soundness, and completeness.

Best role in this block:

- formal logic baseline;
- source for precise definitions;
- good when an agent needs rigor instead of casual reasoning advice.

### OpenLearn — Getting Started with Logic

URL: https://www.open.edu/openlearn/history-the-arts/getting-started-logic/content-section-overview

Use for: beginner-friendly introduction.

Why it matters:

- approachable entry point;
- good for non-specialists;
- useful before formal logic notation becomes heavy.

Best role in this block:

- owner-facing explanations;
- first-pass training material;
- plain-language onboarding.

### Coursera — Introduction to Logic

URL: https://www.coursera.org/learn/logic-introduction

Use for: structured MOOC-style introduction.

Why it matters:

- course format may be easier for self-study than raw textbook material;
- useful when learner wants lessons, exercises, and guided progression.

Best role in this block:

- optional guided learning path;
- check current access, price, audit/certificate terms before recommending commercially.

## Best Materials

### Open Logic Project

URL: https://openlogicproject.org/

Use for: open-source, customizable logic text.

Why it matters:

- open-source collaborative textbook project;
- aimed at mathematical logic for a non-mathematical audience;
- source and PDFs are available;
- useful for advanced or customizable learning paths.

Best role in this block:

- reusable source base;
- formal logic reference;
- material for building custom logic lessons.

### forall x: Calgary

URL: https://forallx.openlogicproject.org/

Use for: complete free textbook on formal logic.

Why it matters:

- covers consequence, validity, truth-functional propositional logic, first-order logic, symbolization, and natural deduction;
- provides PDF, HTML, LaTeX source, and solutions booklet;
- includes accessibility-oriented versions.

Best role in this block:

- main free textbook recommendation;
- exercise source;
- structured curriculum material.

### Stanford Encyclopedia of Philosophy — Logical Consequence

URL: https://plato.stanford.edu/entries/logical-consequence/

Use for: precise conceptual grounding.

Why it matters:

- high-quality academic reference;
- explains why logic is about conclusions following from premises;
- distinguishes deductive and inductive consequence;
- useful for careful definitions and avoiding oversimplification.

Best role in this block:

- definition authority;
- advanced clarification;
- source for agents that need conceptual precision.

### Argument Mapping Overview

URL: https://en.wikipedia.org/wiki/Argument_map

Use for: orientation to argument maps and argument diagrams.

Why it matters:

- explains argument maps as visual representations of premises, conclusions, objections, counterarguments, rebuttals, and inferences;
- useful for teaching agents how to externalize reasoning structure.

Best role in this block:

- practical reasoning visualization;
- bridge between logic theory and project decision review.

## Best Ready-Made Solutions

### Kialo Edu

URL: https://www.kialo-edu.com/

Use for: structured discussion and argument mapping.

Why it matters:

- free tool for thoughtful discussion, critical thinking, participation, deeper comprehension, and civil discourse;
- students build interactive discussion maps by writing pros and cons below each other's points;
- useful for visible reasoning, debate structure, and group decisions.

Best role in this block:

- practical argument map tool;
- debate and decision review;
- teaching structured pro/con reasoning.

### Carnap

URL: https://carnap.io/

Use for: formal logic exercises and course support.

Why it matters:

- free and open software framework for teaching and studying formal logic;
- used by logic courses at dozens of colleges and universities;
- pairs naturally with `forall x: Calgary`.

Best role in this block:

- formal logic practice platform;
- proof/checking exercises;
- course-style logic training.

### Araucaria

URL: http://araucaria.computing.dundee.ac.uk/doku.php

Use for: classic argument mapping and argument diagramming.

Why it matters:

- free software for representing arguments visually;
- supports standard, Toulmin, and Wigmore-style diagrams;
- useful as a historical and methodological reference even if the tool feels old.

Best role in this block:

- argument mapping donor;
- analysis of premise-conclusion structure;
- reference for possible future internal tooling.

### Compendium / IBIS-style Dialogue Mapping

URL: https://en.wikipedia.org/wiki/Compendium_%28software%29

Use for: complex-problem mapping and dialogue mapping.

Why it matters:

- supports mapping ideas, issues, arguments, decisions, references, pros, and cons;
- useful for wicked problems and collaborative reasoning;
- source of donor patterns for project decision maps.

Best role in this block:

- project reasoning workflow donor;
- complex decision-map inspiration;
- possible pattern for central-system review boards.

## Practical Recommendation

For this block, the default stack should be:

1. `forall x: Calgary` for a free textbook foundation.
2. MIT OCW `Logic I` for rigorous course structure.
3. Stanford Encyclopedia of Philosophy for definition precision.
4. Kialo Edu for practical argument mapping and group reasoning.
5. Carnap for formal logic exercises.

Do not overfit the block to symbolic logic only. The owner-facing value is practical reasoning: definitions, cause and effect, assumptions, argument strength, and decision quality.

## Freshness Rule

Course availability, pricing, platform access, certificates, and tool status may change.

Before recommending a paid path, current enrollment, or commercial use, verify the live page again.
