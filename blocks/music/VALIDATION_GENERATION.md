# Music Generation Validation Backlog

Status: candidate
Updated: 2026-06-06

## ACE-Step 1.5

Validate:

- Windows portable installation;
- generation speed on available hardware;
- instrumental background music;
- full songs with vocals;
- Russian and English lyrics;
- duration control;
- BPM, key, and time-signature control;
- reference-audio guidance;
- repaint and cover workflows;
- stem separation;
- REST API reliability;
- VST3 path;
- LoRA workflow;
- license evidence preservation.

## Eleven Music

Validate:

- API access on the selected plan;
- Music v2 quality;
- prompt adherence;
- instrumental and vocal songs;
- multilingual lyrics;
- section-by-section composition;
- inpainting;
- finetune workflow;
- MP3 and WAV export;
- current terms for the intended product.

## Google Lyria 3

Validate:

- region availability;
- Clip model for 30-second outputs;
- Pro model for structured songs;
- custom lyrics;
- timestamp-defined song structure;
- image-conditioned generation;
- WAV output from Pro;
- current terms for the intended product.

## Commercial Embedded APIs

Validate separately:

- SOUNDRAW API;
- Loudly Music API;
- Beatoven maestro API;
- AIVA.

For each provider preserve pricing, rate limits, supported outputs, controls, edit paths, commercial-use evidence, and product-fit notes.

## Evidence Package

Preserve:

- version;
- date;
- hardware profile where relevant;
- prompts and input assets;
- output samples;
- runtime measurements;
- quality notes;
- terms evidence;
- result: promote, keep experimental, or reject.
