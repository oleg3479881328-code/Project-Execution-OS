# Short-Form Patterns

## Purpose

Define reusable creative and editing patterns for Reels, Shorts, and TikTok-style videos.

## Core Rule

Short-form video must earn attention immediately and deliver one clear payoff.

## Hook Types

### Result First

Start with the outcome.

Example structure:

- show surprising result;
- explain how it happened;
- close with CTA or next idea.

### Question Hook

Start with a useful or surprising question.

Use when curiosity is natural.

### Mistake Hook

Start with a common error.

Use for education, tools, products, and comparisons.

### Before / After

Use when transformation is visible.

### List Hook

Use when the value is a compact list.

Examples:

- 3 facts;
- 5 tools;
- 2 mistakes;
- 1 hidden feature.

## Length Guidance

Choose length based on format and payoff.

- ultra-short test: 3 to 8 seconds;
- compact explainer: 10 to 25 seconds;
- fuller short: 25 to 60 seconds;
- extended short: up to platform-supported limits when justified.

Do not stretch weak content to fill time.

## Editing Rhythm

Review:

- first frame clarity;
- hook in first seconds;
- visual changes when attention drops;
- readable captions;
- no dead air;
- clear payoff;
- clear ending.

## Caption Pattern

Captions should be:

- readable;
- synchronized;
- short per line;
- visually consistent;
- placed safely for mobile UI overlays.

## CTA Pattern

Use only one clear action where possible.

Examples:

- follow for part two;
- open the link;
- save this;
- compare the options;
- create your first card.

## Platform Adaptation

Do not blindly repost the same render everywhere.

Review:

- aspect ratio;
- safe zones;
- caption placement;
- platform-native music rules;
- CTA language;
- title/description;
- watermark issues.

## Final Rule

One short video should communicate one main idea. If it needs several explanations, split it into a series.
