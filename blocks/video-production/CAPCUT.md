# CapCut Desktop

## Purpose

Provide reusable CapCut Desktop guidance for manual validation, fast editing, captions, and owner-controlled polish.

## Core Rule

Use CapCut as the manual validation and finishing layer, not as the only automation strategy.

## Best Uses

Use CapCut Desktop for:

- quick prototype edits;
- manual clip trimming;
- caption review;
- template testing;
- transitions;
- music timing;
- owner review;
- final polish before publication.

## Good Workflow

1. import source clip;
2. set project aspect ratio;
3. trim dead air;
4. add or review captions;
5. add hook text;
6. add voiceover or music;
7. review pacing;
8. export platform-ready MP4;
9. record what should later be automated.

## Preset Areas

Standardize:

- 9:16 project format;
- caption style;
- brand font;
- CTA style;
- intro/outro rules;
- logo placement;
- export settings;
- language variant naming.

## What To Automate Later

Move repeatable tasks out of CapCut when proven:

- deterministic clip cutting;
- resizing;
- file naming;
- batch caption preparation;
- voice asset generation;
- export packaging;
- metadata generation.

## Final Rule

Use CapCut to discover the right creative template. Once the template works, automate the repeatable parts around it.
