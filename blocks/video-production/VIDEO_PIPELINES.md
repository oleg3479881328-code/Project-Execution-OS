# Video Pipelines

## Purpose

Define reusable source-to-output pipelines for video production.

## Pipeline 1 — YouTube / Long Video To Shorts

Flow:

`source -> rights check -> import/download -> transcript -> highlight selection -> clip extraction -> vertical crop -> captions -> hook text -> export -> publish package`

Use for:

- podcasts;
- interviews;
- lectures;
- reviews;
- educational videos.

## Pipeline 2 — Gadget Reels Factory

Flow:

`product source -> rights check -> clip selection -> hook -> benefit script -> voiceover -> captions -> CTA -> localized variants -> export -> affiliate metadata`

Use for:

- gadget pages;
- affiliate media;
- product discovery content.

## Pipeline 3 — Facts / Cinema / Documentary Shorts

Flow:

`topic -> source research -> fact verification -> script -> voiceover -> visual sourcing -> edit -> captions -> export -> platform package`

Use for:

- cinema facts;
- science facts;
- historical shorts;
- documentary micro-content.

## Pipeline 4 — Multilingual Content Factory

Flow:

`master video/script -> translation -> local-language QA -> localized TTS -> localized captions -> per-language metadata -> export matrix -> publish queue`

Use for:

- 10-language page networks;
- international affiliate content;
- multilingual educational content.

## Pipeline 5 — QuizLight Video Learning Pipeline

Flow:

`video -> transcript -> timestamp phrase selection -> translation -> context window -> clip boundaries -> multimedia card -> review -> save`

Use for:

- language learning from series;
- YouTube learning;
- transcript-based card creation.

## Pipeline 6 — AI Generated Visual Short

Flow:

`idea -> script -> scene plan -> images/video generation -> voice -> captions -> assembly -> review -> export`

Use for:

- original fact videos;
- anonymous channels;
- educational explainers;
- brand-safe synthetic content.

## Pipeline 7 — Manual Validation Pipeline

Flow:

`source -> small clip -> CapCut -> captions -> export -> publish test -> analytics note`

Use first when testing a new content format.

## Final Rule

Automate only after the manual prototype proves that the content format, hook, pacing, and output quality are good enough.
