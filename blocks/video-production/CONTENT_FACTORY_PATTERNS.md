# Content Factory Patterns

## Purpose

Define reusable scaling patterns for repeatable video production.

## Core Rule

Scale only after one format works manually.

## Pattern 1 — One Source To Many Clips

Use when one long source can yield multiple short videos.

Steps:

1. transcribe;
2. detect candidate moments;
3. rank clips;
4. cut;
5. caption;
6. review;
7. export.

## Pattern 2 — One Master To Many Languages

Use when content is localized across regions.

Steps:

1. create master script;
2. translate;
3. local-language review;
4. generate voice;
5. generate captions;
6. export variants;
7. store per-language metadata.

## Pattern 3 — Topic Batch Factory

Use when one niche needs repeated content.

Examples:

- gadgets;
- cinema facts;
- science facts;
- language phrases;
- product comparisons.

Steps:

1. topic queue;
2. source queue;
3. script queue;
4. render queue;
5. publish queue;
6. analytics feedback.

## Pattern 4 — Template Video Factory

Use when format should remain consistent.

Typical reusable layers:

- intro hook;
- title card;
- caption style;
- voice style;
- logo;
- CTA;
- export settings.

## Pattern 5 — Human Review Gate

Use before publishing at scale.

Review:

- rights;
- factual accuracy;
- language quality;
- audio quality;
- caption accuracy;
- pacing;
- CTA;
- platform fit.

## Pattern 6 — Analytics Loop

Record:

- source;
- niche;
- hook type;
- length;
- language;
- platform;
- watch time;
- completion rate;
- clicks;
- revenue;
- notes.

Use results to refine templates.

## Final Rule

A content factory is not just automation. It is a measured loop that improves formats over time.
