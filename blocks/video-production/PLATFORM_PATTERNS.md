# Platform Patterns

## Purpose

Provide reusable adaptation guidance for major short-form and video platforms.

## Core Rule

Treat each platform as its own distribution surface. Reuse the idea, not blindly the exact render.

## Facebook Reels

Use when:

- testing broad-reach short-form content;
- scaling multilingual pages;
- combining content with affiliate links or page growth.

Review:

- page/account structure;
- original-content expectations;
- monetization eligibility;
- caption placement;
- link strategy;
- reuse/watermark risk.

## TikTok

Use when:

- rapid format testing matters;
- trend-aware short-form content matters;
- product discovery or affiliate workflows matter.

Review:

- hook speed;
- native style;
- music rules;
- account/page policy;
- localized variants;
- commerce restrictions.

## YouTube Shorts

Use when:

- searchable short-form content matters;
- long-form and short-form can reinforce each other;
- channel authority matters.

Review:

- title;
- description;
- channel niche;
- source/originality;
- reuse strategy;
- link/CTA path.

## Instagram Reels

Use when:

- brand aesthetics matter;
- visual polish matters;
- creator-style content matters.

Review:

- safe zones;
- caption style;
- profile conversion;
- consistency;
- story/highlight support.

## Platform Matrix Fields

Track:

- platform;
- account/page;
- language;
- niche;
- aspect ratio;
- duration;
- title;
- description;
- CTA;
- publish date;
- source;
- rights note;
- performance metrics.

## Final Rule

Create a master asset, then adapt metadata, captions, CTA, and sometimes edit pacing per platform.
