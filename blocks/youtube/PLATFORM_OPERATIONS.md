# Platform Operations

## Purpose

Define repeatable operating workflows for maintaining YouTube channels.

## Core Rule

Channel operations should be systematic enough to scale but simple enough to review manually.

## Weekly Operating Loop

1. review analytics;
2. identify winning topics and weak formats;
3. update idea queue;
4. prepare scripts and assets;
5. review rights/originality;
6. produce videos;
7. prepare publish packages;
8. publish or schedule;
9. record outcomes;
10. update experiments.

## Channel Record

Track:

- channel name;
- channel URL;
- language;
- niche;
- account owner;
- status;
- monetization status;
- linked product or affiliate path;
- publishing cadence;
- last publish date;
- notes.

## Video Queue

Track:

- idea;
- channel;
- format;
- topic;
- language;
- script status;
- rights status;
- production status;
- thumbnail status;
- metadata status;
- publish status;
- analytics status.

## Playlist Strategy

Use playlists for:

- topic clusters;
- series;
- learning levels;
- product comparisons;
- long-form sequencing;
- conversion paths.

## Comment / Community Review

Use audience signals for:

- topic ideas;
- objections;
- frequently asked questions;
- language quality feedback;
- product demand;
- next-video planning.

## Scaling Rule

Before adding channels or languages, verify:

- one format works;
- production pipeline is repeatable;
- originality review is reliable;
- metadata workflow is stable;
- analytics comparison exists;
- monetization path is clear.

## Final Rule

Do not scale channel count before one channel has a repeatable production and review loop.
