# Publishing and Metadata

## Purpose

Define reusable YouTube publish-package rules for manual and API-assisted workflows.

## Core Rule

Publish only after editorial, rights, metadata, and channel-routing review.

## Publish Package

For every video store:

- channel;
- language;
- format: Shorts or long-form;
- title;
- description;
- CTA;
- links;
- playlist;
- thumbnail or selected Shorts frame;
- audience setting;
- visibility;
- publish schedule;
- source note;
- rights note;
- review status;
- upload status;
- YouTube video id after upload.

## Title Rules

Titles should:

- make one truthful promise;
- match the actual content;
- fit the audience and format;
- avoid misleading clickbait;
- be localized, not mechanically translated, for multilingual channels.

## Description Rules

Descriptions should include only useful elements:

- concise context;
- CTA;
- relevant links;
- affiliate disclosure when needed;
- source or supporting links when appropriate;
- playlist or next-step path.

## Thumbnail Rules

For long-form:

- use one clear visual idea;
- keep text minimal;
- align thumbnail promise with title and video;
- test patterns through analytics.

For Shorts:

- choose a readable representative frame;
- remember that Shorts thumbnail editing is handled through the mobile YouTube app where applicable.

## Playlist Rules

Use playlists for:

- topic clusters;
- series;
- learning levels;
- product comparisons;
- long-form sequencing;
- channel conversion paths.

## API-Assisted Publishing Rule

Use API automation only after:

- metadata template is proven;
- rights review exists;
- channel routing is verified;
- upload logging exists;
- retries and failure handling exist;
- privacy/default visibility is understood.

## Final Rule

A publish package should be reviewable by a human before the video becomes public.
